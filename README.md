# SRM Academia & Google Classroom AI Biometric Portal

> **An institutional academic management portal inspired by SRM Academia (`academia.srmist.edu.in`) and Google Classroom, unified with real-time AI rotating camera facial recognition attendance tracking in an executive luxury aesthetic (Obsidian Black, Charcoal, Espresso Brown, and Champagne Bronze).**

---

## 🏛️ Key Features

### 1. SRM Academia Authentication
- **Role-based Authentication**: Separate portals for **Student** and **Faculty**.
- Uses official SRMIST NetID & Register Number credential formats.
- **Quick 1-Click Demo Logins**:
  - **Student Demo**: NetID `ra2211003010123` | Password `password123` (*Aarav Sharma*)
  - **Faculty Demo**: NetID `faculty_srm` | Password `password123` (*Dr. Rajesh K. Sundaram*)

### 2. Student Portal
- **My Classrooms**: Enrolled Google Classroom streams. View posts, lecture notes, syllabus links, and media attachments.
- **Attendance & Margin Bunk Calculator**:
  - SRMIST mandatory threshold: **75.0%**.
  - Circular attendance dial showing overall percentage.
  - Course-by-course breakdown with exact **Margin Bunk Allowance**:
    - **Safe Bunk**: e.g., `+8 classes can be safely missed` (stays above 75%).
    - **Deficit Alert**: e.g., `Must attend next 8 consecutive classes to reach 75%`.
- **Time Table**: Day Order 1 through Day Order 5 schedule grid with periods 1 to 6, course codes, room numbers (Tech Park 704, TP Labs), and faculty names.
- **Internal Marks (CLA)**: Continuous Learning Assessment 1 (25M), CLA-2 (25M), Assignments (10M), Model Exam (50M), Total Internal marks.
- **Exam Seating Planner**: Official hall ticket details including exam date, session (FN/AN), exam hall (`Tech Park 704`), and seat number (`TP-704-B12`).
- **Join Classroom**: Join any teacher's class instantly using a 6-character Class Code (e.g. `SRM-DL01`).

### 3. Faculty / Teacher Portal (Google Classroom Ecosystem)
- **Classroom Creator**: Create new classes with Subject Name, Course Code (e.g. `18CSC305J`), Section (`CSE-B`), and generate unique 6-character Class Codes.
- **Classroom Stream**: Post announcements, attach images, video links, or course resources.
- **Live AI Rotating Camera Sweep**:
  - Select any classroom from dropdown.
  - Launch live rotating camera sweep.
  - Only students enrolled in that class are matched and verified.
  - Automatically records attendance with proof snapshots and updates student's Academia attendance and margin in real time!
- **Biometric Student Studio**: Register new students with live webcam photo snap or file upload with automatic 128-D face embedding extraction.
- **Attendance Dossiers**: View historical sessions and export formatted CSV and printable administrative reports.

### 4. Luxury Classic Design ("Full Classy")
- Elegant executive palette: **Deep Obsidian Black (`#0c0c0e`)**, **Charcoal (`#141418`)**, **Rich Espresso (`#2a1f18`)**, **Warm Mahogany (`#423026`)**, and **Champagne Bronze / Muted Gold (`#c59b6d`, `#d4af37`)**.
- Editorial typography: `Cinzel`, `Playfair Display`, and `Plus Jakarta Sans`.
- AI Face Recognition HUD updated to refined champagne bronze corner brackets and jade green verification badges.

## 🚀 How to Run

### Quick Start
Double-click `run_app.bat` or execute:
```bash
python app.py
```
Open your browser at:
```
http://127.0.0.1:5000
```

### Testing the Workflow:
1. **Student Login**: Click `⚡ Student Demo (Aarav Sharma)`. Check your **Attendance & Margin Calculator**, **Time Table**, and **Exam Seating**.
2. **Faculty Login**: Click Logout, then click `⚡ Faculty Demo (Dr. Rajesh Sundaram)`.
3. Create a new classroom or open an existing class stream to post an announcement with an image/link.
4. Switch to **AI Rotating Camera Attendance**, select `Deep Learning (18CSC305J)`, and start the sweep!
5. Rotate/pan your camera: students are recognized, and their attendance and bunk margin update in real time!
